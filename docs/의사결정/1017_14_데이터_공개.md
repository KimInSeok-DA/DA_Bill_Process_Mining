# 1017_14 가공한 이벤트 로그 공개

- 상태: 확정 (사용자 결정, 2026-10-17. 2026-10-16 선택 과제 순서의 마지막)
- 배경: 1015_07에서 이벤트 로그 CSV를 "재배포 조건 확인 전이라" 공개하지 않고 다시 만드는 방법만 안내했다. 바꾸는 조건이 "이용약관을 확인해 허용되면 공개 검토"였다

## 1. 확인한 것 (2026-10-17)

| 출처 | 내용 |
|---|---|
| 열린국회정보 Open API 이용약관(2020-02-17 시행) | 재배포를 금지하는 조항이 없다. 제5조 금지사항은 사칭·악성코드·저작권 위반 정보와 결합·연결방식 위변조·인증키 양도·권한 없는 접근. 제7조는 출처 표시 의무("출처 : 열린국회정보, 서비스 메뉴명, 날짜") |
| 열린국회정보 저작권 정책 | 저작권법 제24조의2(공공저작물의 자유이용)에 따라 공공누리 제1유형(출처표시)이 붙은 자료는 별도 허락 없이 자유이용 가능. 데이터마다 이용허락조건을 확인하라고 함 |
| API 목록(`OPENSRVAPI`)의 이용허락 항목 `CCL_NM` | 이 프로젝트가 쓴 4개 서비스 모두 "출처표시": 국회의원 발의법률안, 법률안 심사 및 처리(의안검색), 소위 심사정보(법률안), 의안 위원회심사 회의정보 조회. 전체 280개 중 279개가 "출처표시", 1개가 "출처표시 + 상업적 이용금지" |
| 이벤트 로그 내용 | 의원 이름 없음(제안자 종류만). 의안 ID·번호·단계·날짜·위원회 |

- 결론: 출처를 표시하면 가공한 데이터를 다시 배포할 수 있다

## 2. 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 22대만 압축해 저장소에(약 1.7MB) | 키 없이 바로 분석. pandas·pm4py가 .gz를 그대로 읽음 | 21대 실험은 여전히 직접 수집 |
| **22대 + 21대 압축본을 저장소에(약 3.8MB)** | 21대 절단 실험까지 키 없이 다시 해 볼 수 있음 | 저장소가 약 4MB 늘어남 |
| GitHub Release로 공개 | 저장소가 가벼움 | Release를 사용자가 따로 만들어야 하고, 코드와 데이터 버전이 따로 놂 |
| 공개하지 않음 | 지금과 같음 | 보는 사람이 인증키를 받아 1시간 넘게 수집해야 함 |

## 3. 결정

- **22대 + 21대 압축본을 `data/public/`에 올린다**(사용자 선택). 추천은 22대만이었으나, 사용자가 21대 실험 재현까지 포함하기로 했다
- 올리는 것: 이벤트 로그, 규칙으로 뺀 기록, 처리 전후 대조(`build_report.json`), 22대 원안-대안 연결. 올리지 않는 것: API 원본(`data/raw/`), 회의정보·화면 원본, OCEL(다시 만들 수 있고 원본에 가까움)
- 출처 표시: `data/public/README.md` 첫머리와 루트 README 데이터 절. 열 설명과 알아 둘 점(첫 날짜만 씀, 마지막 회부만 있음)을 함께 적는다
- 만드는 코드: `src/export_public.py`. gzip 시각을 0으로 고정해 같은 입력이면 같은 파일이 나오고, 압축 전후 줄 수를 대조한다
