## 3. 이벤트 로그 CSV 공개

| 후보 | 장점 | 단점 |
|---|---|---|
| 공개하지 않음, 다시 만드는 방법 안내 | 재배포 조건 확인 없이 안전. 저장소가 가벼움 | 보는 사람이 인증키를 받아 직접 수집해야 함(약 1시간) |
| CSV 그대로 공개(18MB) | 키 없이 바로 분석 가능 | 버전마다 18MB가 쌓임. 원본에 가까운 데이터를 다시 배포하는 것이라 이용약관상 재배포 조건 확인 필요 |
| 압축본·GitHub Release로 공개 | 저장소는 가벼움 | 관리할 것이 늘어남. 재배포 조건 문제는 같음 |

- 결정: 공개하지 않고 README "실행 방법"에 인증키 발급부터 교차 검증까지 단계별로 안내한다
- 근거: 결과 검증에 필요한 것(코드, 처리 전후 건수 대조 `build_report.json`, 집계 표, 교차 검증 결과)은 이미 공개되어 있다
- 바꾸는 조건: 열린국회정보의 재배포 조건(이용약관)을 확인해 허용되면 Release로 공개를 검토한다
