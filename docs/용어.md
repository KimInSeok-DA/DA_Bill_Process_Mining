# 용어 정리

이 저장소의 보고서·문서에 나오는 용어를 처음 보는 사람도 읽을 수 있게 정리했다. 국회 절차 용어는 이 분석에 필요한 범위에서 풀어 썼다.

## 1. 법률안이 처리되는 길 (한눈에)

```
제안 ─▶ 소관위 회부 ─▶ 소관위 상정 ─▶ 소위 회부 ─▶ 소위 상정 ─▶ 소위 처리 ─▶ 소관위 처리
                                                                              │
                     ┌────────────────────────────────────────────────────────┤
                     ▼                                                        ▼
        법사위 회부 ─▶ 법사위 상정 ─▶ 법사위 처리 ─▶ 본회의(가결·부결)        대안반영폐기
                                                                    (원안 대신 위원회 대안이 본회의로)
```

- 모든 의안이 이 길을 끝까지 가는 것은 아니다. 대부분은 중간 단계에 머물러 있다(계류)
- 22대 국회는 2024-05-30에 시작했다. 임기가 끝날 때까지 처리되지 않은 의안은 폐기된다(임기만료폐기)

## 2. 국회 절차 용어

| 용어 | 뜻 |
|---|---|
| 법률안 | 법을 새로 만들거나 고치자는 안. 이 분석의 대상(예산안·결의안 등 다른 의안은 제외) |
| 의안 | 국회에서 다루는 안건. 법률안은 의안의 한 종류 |
| 제안(발의) | 법률안을 국회에 내는 것. 국회의원(10인 이상 찬성)이 내면 의원안, 정부가 내면 정부안 |
| 위원회 | 분야별로 법률안을 심사하는 국회의원 모임. 상임위원회(교육위원회, 보건복지위원회 등 17개)와 한시적인 특별위원회가 있다 |
| 소관위원회(소관위) | 그 법률안을 맡아 심사하는 위원회. 법률안의 분야에 따라 정해진다 |
| 소위원회(소위) | 위원회 안의 작은 모임. 법률안을 조문별로 자세히 심사한다(법안심사소위원회 등). 실제 심사는 대부분 여기서 이뤄진다 |
| 전체회의 | 위원회 위원 전원이 모이는 회의. 소위 심사 결과를 보고받아 위원회의 결론을 낸다 |
| 회부 | 법률안을 위원회(또는 소위)에 넘겨 심사를 맡기는 것 |
| 상정 | 회의의 안건으로 올려 실제로 다루기 시작하는 것. 회부되어도 상정되지 않으면 심사가 시작되지 않는다 |
| 처리 | 회의에서 결론을 내는 것. 결론은 가결·부결·대안반영폐기·회송 등이다. 이 분석의 "소위 처리", "소관위 처리", "법사위 처리"는 각 단계에서 결론이 난 날이다 |
| 의결 | 회의에서 표결 등으로 결정하는 것. 처리의 한 방식 |
| 법제사법위원회(법사위) 체계·자구 심사 | 소관위를 통과한 법률안이 다른 법과 충돌하지 않는지, 용어가 맞는지 법사위가 검토하는 단계(국회법 제86조) |
| 본회의 | 국회의원 전원이 모이는 회의. 법률안을 최종 의결한다 |
| 가결 / 원안가결 / 수정가결 | 통과. 원안가결은 낸 그대로, 수정가결은 고쳐서 통과. 이 분석에서는 둘을 "가결"로 묶었다 |
| 부결 | 통과되지 않음 |
| 대안 | 위원회가 비슷한 법률안 여러 건을 합쳐 새로 만든 법률안. 위원장 이름으로 낸다 |
| 원안 | 대안과 구분해, 의원이나 정부가 처음 낸 법률안. 이 분석에서는 의원안과 정부안을 "원안"이라 부른다 |
| 대안반영폐기 | 원안의 내용이 대안에 반영되어, 원안 자체는 본회의에 가지 않고 폐기되는 것. 내용은 대안으로 살아남으므로 실질적으로는 통과와 비슷하다 |
| 위원회안 | 원안 없이 위원회가 직접 마련해 내는 법률안. 이 분석에서는 대안과 함께 "위원회안"으로 묶었다 |
| 위원회 제출 | 위원회가 대안·위원회안을 법사위 체계·자구 심사를 반영해 최종 제출하는 것. 데이터상 대안의 "제안일" |
| 수정안반영폐기 | 원안의 내용이 다른 법률안의 수정안에 반영되어 폐기되는 것 |
| 철회 | 낸 사람이 법률안을 거둬들이는 것 |
| 폐기 | 처리되지 않거나 의결로 없어지는 것 |
| 계류 | 처리되지 않고 위원회 등에 머물러 있는 상태 |
| 회송 | 위원회가 법률안을 돌려보내는 것(관할이 바뀐 경우 등) |
| 소위 직접 회부 | 전체회의를 거치지 않고 소위에 바로 회부하는 것(국회법 제58조제4항). 이때 소관위 상정은 소위 심사 뒤에 온다 |
| 재회부 | 위원회 개편이나 특별위원회 설치로 법률안이 다른 위원회에 다시 회부되는 것 |
| 위원회 개편 | 위원회 이름·맡는 분야가 바뀌는 것. 22대 국회에서는 기획재정위원회 → 재정경제기획위원회, 환경노동위원회 → 기후에너지환경노동위원회, 여성가족위원회 → 성평등가족위원회 |
| 신속처리안건 | 지정되면 정해진 기간이 지났을 때 다음 단계로 넘어간 것으로 보는 법률안(국회법 제85조의2) |
| 예산부수법안 | 예산안과 함께 처리해야 하는 법률안. 기한까지 심사를 마치지 못하면 본회의에 자동으로 올라간다(국회법 제85조의3) |

## 3. 프로세스 마이닝·통계 용어

| 용어 | 뜻 |
|---|---|
| 프로세스 마이닝 | 시스템에 남은 기록(이벤트 로그)으로 실제 업무 흐름을 찾고, 어디서 오래 걸리는지 분석하는 방법 |
| 이벤트 로그 | "누가(케이스), 무엇을(활동), 언제(시각)" 했는지 한 줄씩 적은 표. 이 프로젝트에서는 법률안 1건의 단계별 날짜를 한 줄씩 펼쳤다 |
| 케이스 | 따라가는 대상 하나. 여기서는 법률안 1건 |
| 활동 | 케이스에 일어난 일. 여기서는 제안·회부·상정·처리 같은 단계 |
| 시각(타임스탬프) | 활동이 일어난 때. 여기서는 날짜(일 단위) |
| 프로세스 지도(직접 이어짐 그래프, DFG) | 활동을 상자로, "A 바로 다음에 B가 일어난 횟수"를 화살표로 그린 그림 |
| 변형(variant) | 케이스가 지나온 활동 순서 하나. 같은 순서를 밟은 케이스는 같은 변형이다 |
| 병목 | 흐름에서 오래 기다리는 구간 |
| 구간 대기 | 앞 활동에서 다음 활동까지 걸린 날수 |
| 진행 중 케이스 | 조회일(2026-10-15)까지 끝나지 않은 케이스 |
| 중도절단(right censoring) | 관찰이 끝날 때까지 결과가 나오지 않은 경우. 이런 케이스를 빼고 끝난 것만 보면 대기가 실제보다 짧게 보인다 |
| 생존분석 · Kaplan-Meier(KM) | 중도절단된 케이스까지 포함해 "시간이 지나면서 아직 다음 단계로 못 간 비율"을 계산하는 방법. 그 비율이 절반 아래로 내려가는 날이 KM 중앙값이다 |
| 생존곡선 | KM으로 계산한 "아직 다음 단계로 못 간 비율"을 날짜에 따라 그린 선. 천천히 내려갈수록 오래 기다린다 |
| 관찰 중앙값 | 두 활동이 모두 일어난 케이스만 보고 낸 대기일 중앙값. 진행 중 케이스가 빠진다 |
| 계류(조회일 기준) | 지금 어떤 단계를 기다리는 진행 중 케이스의 수와, 그 단계에 들어온 뒤 지난 날수 |
| 중앙값 / 90분위 | 한가운데 값 / 작은 쪽에서 90% 지점의 값(긴 쪽 꼬리를 보여 줌) |
| 묶음 처리 | 같은 날 같은 위원회에서 여러 의안을 한꺼번에 처리하는 것 |
| 교차 검증 | 같은 지표를 다른 도구(pm4py·pandas 대 SQL)로 처음부터 다시 계산해 값이 같은지 맞춰 보는 것 |
| 적합성 검사(conformance checking) | "이렇게 처리돼야 한다"는 절차 모델을 정해 두고, 실제 기록이 그 모델과 얼마나 맞는지, 어디서 벗어나는지 재는 분석 |
| 상태 전이도 | "지금 이 상태에서는 다음에 이 활동만 올 수 있다"를 표로 정한 모델. 이 프로젝트의 표준 절차 모델 |
| 페트리넷 | 프로세스 모델을 그리는 표준 형식. 상태 전이도는 페트리넷의 한 종류다 |
| 정렬(alignment) | 실제 경로를 모델의 가장 가까운 경로에 맞추며, 모델에 없는 활동과 실제로 빠진 단계를 세는 방법 |
| 적합도(fitness) | 실제 경로가 모델과 얼마나 맞는지 나타내는 0～1 값. 1이면 완전히 일치 |

## 4. 이벤트 로그의 열 (`data/processed/event_log.csv`)

| 열 | 뜻 |
|---|---|
| `case_id` | 의안 ID(열린국회정보 `BILL_ID`) |
| `bill_no` | 의안번호 |
| `activity` | 활동 이름(18가지: 제안, 소관위 회부·재회부·상정·처리, 소위 회부·상정·처리, 법사위 회부·상정·처리, 위원회 제출, 가결, 부결, 대안반영폐기, 수정안반영폐기, 철회, 폐기) |
| `date` | 활동 날짜 |
| `step_order` | 같은 날 활동의 순서를 정하는 절차 번호(1 제안 ～ 11 끝 활동). 소위가 먼저 심사한 경로의 소관위 상정은 6.5, 위원회 제출은 10.5 |
| `committee` | 그 활동을 맡은 위원회 |
| `sub_committee` | 소위 활동의 소위원회 이름 |
| `stage_result` | 처리 활동의 결과(원안가결, 대안반영폐기 등) |
| `case_status` | 완료 / 진행중(조회일 기준) |
| `final_result` | 의안의 최종 처리 결과(진행 중이면 빈칸) |
| `case_committee` | 의안의 현재 소관위원회 |
| `proposer_kind` | 제안자 구분: 의원 / 정부 / 위원장 |
| `case_group` | 원안(의원·정부) / 위원회안(대안·위원회안) |
| `alt_bill_no` | 원안을 흡수한 대안의 의안번호(대안반영폐기 등) |

원안-대안 연결 표(`alt_links.csv`)는 대안 1건과 그 대안이 흡수한 원안 1건을 한 줄로 적는다.
