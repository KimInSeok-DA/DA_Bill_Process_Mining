# 공개 데이터: 국회 법률안 이벤트 로그

열린국회정보 Open API로 받은 원본을 이 프로젝트의 규칙으로 가공한 이벤트 로그입니다. 인증키 없이 바로 분석할 수 있습니다.

출처: 열린국회정보, 국회의원 발의법률안·법률안 심사 및 처리(의안검색)·소위 심사정보(법률안), 2026-10-15 조회. 위 서비스의 이용허락 조건은 "출처표시"(공공누리 제1유형)입니다. 이 파일을 다시 쓸 때도 위 출처를 함께 적어 주세요.

## 파일

| 파일 | 줄 | 내용 |
|---|---|---|
| `age22/event_log.csv.gz` | 107,808 | 22대 국회 법률안 21,326건의 단계별 기록(제안일 2024-05-30～2026-10-14) |
| `age22/excluded_events.csv.gz` | 925 | 규칙에 따라 이벤트 로그에서 뺀 기록과 이유 |
| `age22/alt_links.csv.gz` | 4,469 | 대안 1건이 흡수한 원안 목록 |
| `age22/build_report.json` | | 처리 전후 건수 대조(활동별 원본 − 규칙 제외 − 중복 합침 = 로그) |
| `age21/event_log.csv.gz` | 160,107 | 21대 국회 법률안 25,858건(임기 2020-05-30～2024-05-29). 원안-대안 연결은 없음 |
| `age21/excluded_events.csv.gz` | 1,397 | 21대에서 규칙에 따라 뺀 기록 |
| `age21/build_report.json` | | 21대 처리 전후 건수 대조 |

pandas는 압축을 풀지 않고 바로 읽습니다.

```python
import pandas as pd
log = pd.read_csv("data/public/age22/event_log.csv.gz", dtype=str)
```

이 저장소의 분석 코드를 인증키 없이 돌리려면 압축을 풀어 `data/processed/`(21대는 `data/processed/age21/`)에 둡니다. `analysis.py`·`figures.py`·`conformance.py`·`age21.py`가 이것만으로 돌아갑니다. 지연 법률안 특징·OCEL(법률안 이름이 필요), 회의정보, 화면 확인, 교차 검증은 API 원본이 필요합니다.

## 열 (event_log, excluded_events)

| 열 | 뜻 |
|---|---|
| `case_id` | 의안 ID(`BILL_ID`). 케이스 = 법률안 1건 |
| `bill_no` | 의안번호 |
| `activity` | 단계(18가지): 제안, 소관위 회부, 소관위 재회부, 소관위 상정, 소위 회부, 소위 상정, 소위 처리, 소관위 처리, 법사위 회부·상정·처리, 위원회 제출, 끝 활동 6가지(가결, 부결, 대안반영폐기, 수정안반영폐기, 철회, 폐기). 21대에는 끝 활동 임기만료폐기가 더 있음 |
| `date` | 그 단계의 날짜(일 단위) |
| `step_order` | 같은 날 거친 단계를 절차 순서대로 정렬하는 값 |
| `committee` | 그 단계를 맡은 위원회(위원회 개편 전 이름 그대로) |
| `sub_committee` | 소위원회 이름(소위 단계만) |
| `stage_result` | 그 단계의 처리 결과(소관위·법사위 처리 등) |
| `case_status` | 조회일 기준 완료 / 진행중 |
| `final_result` | 끝 결과(진행중이면 비어 있음) |
| `case_committee` | 법률안을 지금 맡은 소관위 |
| `proposer_kind` | 제안자 종류: 의원, 정부, 위원장(의원 이름은 넣지 않음) |
| `case_group` | 원안(의원·정부) / 위원회안(위원장 제안 대안·위원회안) |
| `alt_bill_no` | 원안을 흡수한 대안의 의안번호(22대만) |
| `exclude_reason` | 뺀 이유(excluded_events만) |

## 열 (alt_links)

| 열 | 뜻 |
|---|---|
| `alt_bill_id`, `alt_bill_no` | 대안의 의안 ID·번호 |
| `orig_bill_id`, `orig_bill_no` | 흡수된 원안의 의안 ID·번호 |
| `orig_result` | 원안의 처리 결과 |
| `orig_kind` | 원안 제안자 종류 |

## 알아 둘 것

- 정의와 규칙: [1015_03 이벤트 로그 정의](../../docs/의사결정/1015_03_이벤트로그_정의.md), [1015_06 범위 확장](../../docs/의사결정/1015_06_범위확장_정부안_위원회안.md), [1016_09 21대 비교](../../docs/의사결정/1016_09_21대_비교.md)
- 단계마다 첫 날짜만 씁니다. 같은 법률안을 소위가 여러 번 심사한 기록은 들어 있지 않습니다
- API는 소관위 회부를 마지막 한 번만 줍니다. 다른 위원회로 다시 회부된 법률안은 "제안 → 회부"가 실제보다 길 수 있습니다([1017_13](../../docs/의사결정/1017_13_회부_지연_확인.md))
- 국회 데이터는 매일 바뀝니다. 이 파일은 2026-10-15 조회 시점의 기록입니다
- 만드는 코드: `src/build_event_log.py` → `src/export_public.py`
